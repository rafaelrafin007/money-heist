# Play Store Readiness

Money Heist is not ready for public Play Store release until every item below is reviewed with real production accounts, production Supabase configuration, and release signing controlled through EAS.

## Required Before Public Release

- Publish a privacy policy URL and add it to Play Console.
- Prepare the Google Play Data safety form from the actual data collected by the app.
- Add a support contact email.
- Prepare screenshots for common Android phone sizes.
- Prepare a feature graphic and short/long app descriptions.
- Complete age rating and content rating questionnaires.
- Review the app name and branding outside the codebase before store submission.
- Confirm production Supabase Auth email templates and redirect URLs.
- Configure `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` for the EAS build environment.
- Confirm no service-role key, database password, JWT secret, signing key, keystore, or access token is present in the app or repository.
- Run internal testing before closed or public testing.
- Run crash testing on a physical Android device and Expo web.
- Review final permissions in the resolved Expo config.
- Keep versioning aligned: public version in `app.json`, Android version code increased for every store upload.
- Use APK only for direct internal install testing. Use AAB for Play Store release.
- Keep signing credentials backed up through the proper EAS credentials flow.

## Account Deletion Readiness

Account deletion is a release blocker until a safe server-side process exists.

Do not add a client-only delete-account button. Deleting the authenticated user and all owned finance records requires privileged backend execution, audit-safe cleanup, and clear user confirmation. Service-role credentials must never be placed in the Expo app.

## Final Local Checks

- `npm run lint`
- `npx tsc --noEmit`
- `npm run test:run`
- `npx expo config --type public`
- `npx expo export --platform web`
- `npx expo export --platform android`

Confirm no `android/` or `ios/` directory is generated by these checks.
